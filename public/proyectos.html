Proyectos

Proyectos de desarrollo web realizados por Omar Rodrigo Mamani Capcha: aplicaciones full stack, sistemas de gestión y juegos web.

Plataforma full-stack para la evaluación externa del desempeño de laboratorios de salud (INLASA, Bolivia). Desarrollado end-to-end (~68 controladores, 46 modelos, 219 vistas): arquitectura RBAC multi-rol, certificados PDF con QR de verificación, exportación a Excel, dashboards con Chart.js, motor de formularios dinámicos y módulo estadístico ISO 13528.

Plataforma de eventos e inscripciones con tres formas de acceso: web, API REST y un servidor MCP para que asistentes de IA busquen eventos e inscriban usuarios. Roles (admin, organizador, participante), control de cupos y asistencia, certificados y reportes en PDF/Excel, correos en cola con Redis, tareas programadas y despliegue en AWS EC2 con Docker y Terraform.

El backend maneja la lógica del juego, autenticación de usuarios y gestión de datos. Se utiliza autenticación JWT para proteger las rutas y cifrar contraseñas, además de administrar los datos del juego y usuarios de forma segura.

Es un juego de matemáticas con cuatro niveles: Básico, Intermedio, Avanzado y Pro. Los jugadores resuelven sumas, restas, multiplicaciones y divisiones que se vuelven más difíciles en cada nivel. En los últimos niveles hay un temporizador para aumentar el reto. Los usuarios pueden crear una cuenta, iniciar sesión y ver sus puntuaciones.

Permite a los usuarios autenticarse con Google para gestionar sus horarios, archivos y listas de tareas, y para el almacenamiento se usan los servicios de Firebase.
